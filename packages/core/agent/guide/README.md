# dsh-agent 导读（易懂版）

这份导读把包根目录 [README.zh.md](../README.zh.md) 里偏合同语气的内容，拆成按主题阅读的说明。
官方 README 仍是权威合同（API、模型体验、已知限制）；这里只负责**讲清楚在干什么**。

**先看图，再下钻。** [00-总览.md](./00-总览.md) 用对象关系图和运行时序把各章串在一张地图上；后面每章只讲地图上的一块。
