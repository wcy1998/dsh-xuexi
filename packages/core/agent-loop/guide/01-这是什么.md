# 01 — 这是什么

对应总览：[对象关系](./00-总览.md#objects)

## 一句话

`@deepseek-ai/dsh-agent-loop` 是 harness 里**唯一包含具体循环逻辑**的包：实现 `Agent`、驱动 turn/step、调模型、跑工具。

可以把它想成：

| 角色 | 类比 |
|------|------|
| [`dsh-agent`](../../agent/guide/01-这是什么.md) | 遥控器说明书 + 设备登记册 |
| **本包** | 具体电视机的内部电路 |
| UI / ACP / 钩子 | 按说明书按按钮的人 |

换循环实现时，只要仍提供同一套 `Agent` 接口并通过 `ctx.agents` 注册，遥控器用法不变。**默认发行版只带本包这一台。**

## 你在代码里会碰到什么

1. **`ctx.agentLoop`（`AgentLoop`）**：服务；实现 `AgentFactory`；配置驱动的 `create(id)`；把工厂挂到 `ctx.agents`。
2. **`ReactLoopAgent`**：包内驱动器，**不**出现在包导出映射里；生命周期方通过 `ctx.agents` 拿到 `Agent` 把手，不直接 `new`。
3. **会话日志**：`turn/*`、`step/*`、`assistant/*`、`tool/*`、`request/header` —— 模型可见内容的权威来源。
4. **实时 `agent/*`**：与 `dsh-agent` 声明的同一套词汇；本包在驱动路径上发出它们。

## 和 `dsh-agent` 的边界

| 包 | 管什么 |
|----|--------|
| `dsh-agent` | `Agent` 接口、`Inbox`、注册表、发起方 ALS、事件名、`installModelSelection` |
| **本包** | 认领 inbox、跑 turn/step、组装请求、流式 LLM、调度工具、取消收敛、配置创建 agent |

**新行为进插件，不进这里**（压缩、重试、权限、subagent、UI 都听事件）。

## 依赖的五个服务

`agents`、`sessions`、`llm`、`tools`、`systemPrompt` —— 全部注入；缺一不可驱动。

## 可选诊断

`@deepseek-ai/dsh-agent-loop/invariant`：检查循环发出的 LLM 请求能否从会话日志重建。根服务不隐式加载。
