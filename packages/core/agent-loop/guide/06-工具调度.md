# 06 — 工具调度

对应总览：[工具调度](./00-总览.md#tools)

入口：`executeToolCalls`（[`tool-calls.ts`](../src/tool-calls.ts)）。在 `withInitiator` 边界内，`requireInitiator()` 得到当前 Agent。

## 调度规则

| 模式 | 行为 |
|------|------|
| **exclusive** | 屏障：独占跑完再考虑后面 |
| **parallel-safe** | 有界滚动池（`maxParallelToolCalls`，默认 10） |
| 启动前 | 重新分类（模式可变） |

重叠的是**分发与执行主体**；策略、持久 `tool/result`、结果上下文仍按**模型顺序**提交。

## Abort

```text
停新分发
  → 等已启动调用的结果处理完
  → 未启动的：合成 tool/call + ABORTED_BEFORE_DISPATCH 结果
  → 已启动的结果上下文仍可进入下一步 inbox（经 acceptContext）
```

内部调度器故障：停新分发、排空已启动、**不**虚构结果，再进 turn 错误边界。

## `concludesTurn`

某结果带 `concludesTurn` 可在本步结束 turn；同一步已提交的 next-step / 竞态 steering 仍会跑完再关。

## 策略不在本包

拒绝 / 询问 / 沙箱：听 `tools/pre-execute` 等（`dsh-tools`）。本包只调度与记日志。
