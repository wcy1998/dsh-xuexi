# 08 — 模型体验与已知限制

对应总览：[一轮 turn](./00-总览.md#turn)

## 模型体验（压缩版）

### 完整对话请求

- 每步发送：该 agent 的系统提示词、可见工具 schema、会话派生消息。
- 本包提供 `provider` / `model` / `cwd` 变量，不加固定文案。
- 系统文本与 schema **每步重计**；组装 waterfall 可改最终请求。

### KV Cache

仅当同 provider/model，且系统文本、schema、此前历史逐字节一致时，请求序列才保持仅追加。携带 token 的组装改写可能从第一个改变的 token 起使复用失效。

### 保留的历史

已接纳的 user / assistant / 工具 / inject / steer 会进入后续步骤。原始 chunk、生命周期边界等仅日志事件排除。历史随表层消息增长，直到压缩遮蔽。

### 取消后未分发的调用

回放中止步骤时，每个未分派工具调用带 `ABORTED_BEFORE_DISPATCH`，固定错误文案；仅追加，不使已有 KV 失效。

## 插件该挂哪里（提醒）

| 你想做的事 | 走哪里 |
|------------|--------|
| 拒步骤 / 改批次 | `agent/pre-step` |
| 换请求配置 | `agent/request` |
| 溢出恢复 / 重试 | `agent/request-error`（如 `dsh-llm-retry`、compaction） |
| 工具策略 | `tools/*` 流水线 |
| subagent | `ctx.subagents` + `ctx.agents.create`，不在 `Agent` 方法上 |
| UI 时间线 | `session/event` + `agent/status` 等 |

## 已知限制（人话）

1. **工具分类是一元的** — 依赖同级比较的调用须标 exclusive。  
2. **配置 label 默认新会话** — 省略稳定 `sessionId` 时每次启动新 UUID；要恢复须显式 `sessionId` / `resumeSessionId`。  
3. **配置 agent 无逐 agent persona/setup** — 只有编程式 create/resume 的 setup 能组合作用域世界。  
4. **没有内置轮次预算** — 工具或 steer 会让 turn 继续；限失控须在扩展点（如 `agent/turn-stopping`）取消。
