# 00 — 总览：先把图看懂

后面每一章都是这几张图上的一块。卡住时回到这里对位置。

本包实现 **`AgentLoop`（`ctx.agentLoop`）**：具体循环驱动器。它通过 `ctx.agents.setFactory(this)` 成为创建工厂；真正开车的是包内 **`ReactLoopAgent`**（不对外导出）。接口词汇在 [`dsh-agent`](../../agent/guide/README.md)。官方细图：[架构 · 轮次流程](../../../../docs/architecture.zh.md#turn-flow)、[时序图](../../../../docs/agent-lifecycle.zh.md)。

一张图记住一生：

```mermaid
flowchart LR
  C["create / resume"] --> P["setup 未发布"]
  P --> A["enter + announce<br/>session-start"]
  A --> I["idle"]
  I -->|"followup / steer"| R["running"]
  R --> T["turn"]
  T -->|"pre-step → request → 工具"| S["step*"]
  S --> T
  T -->|"inbox 仍有活"| T
  T -->|"停稳"| I
  I --> X["dispose"]
```

## 2. 从创建到能说话

```mermaid
sequenceDiagram
  participant UI as 调用方
  participant REG as ctx.agents
  participant LOOP as AgentLoop
  participant SETUP as setup
  participant A as ReactLoopAgent

  UI->>REG: create / resume
  REG->>LOOP: createAgent / resume
  LOOP->>LOOP: prepare 会话 + 未发布 agent
  LOOP->>SETUP: await setup(agentCtx)
  Note over SETUP: 只组合，不能 followup
  SETUP-->>LOOP: 可选 commit()
  LOOP->>LOOP: sessions.enter + agents.enter
  LOOP->>LOOP: announce session + agent
  LOOP-->>UI: agent/created
  LOOP-->>UI: agent/session-start
  LOOP->>A: 驱动器已可唤醒
  LOOP-->>UI: AgentHandle
```

同 id 可并行准备，只有一个能 `enter`。创建专用 `signal` 只取消未发布阶段。细节：[02](./02-AgentLoop服务.md)。

## 3. 用户发一条消息之后（本包主路径）

```mermaid
sequenceDiagram
  participant U as 用户或插件
  participant A as ReactLoopAgent
  participant IB as inbox
  participant LOG as 会话日志
  participant H as agent/* 监听器
  participant LLM as ctx.llm
  participant T as ctx.tools

  U->>A: followup / steer / inject
  A->>IB: splice 写入
  alt followup 或 steer
    A->>A: wakeDriver → status running
  end

  A->>LOG: turn/start
  A->>IB: claim
  A->>H: agent/pre-step
  alt reject / 空批
    A->>LOG: turn/end 无 step
  else enter
    A->>LOG: step/start + user/message
    A->>H: agent/request
    A->>LLM: stream
    LLM-->>LOG: assistant/chunk* + assistant/message
    A->>T: executeToolCalls
    A->>LOG: step/end
    opt 可结束且 next-step 空
      A->>H: agent/turn-stopping
    end
  end
  A->>LOG: turn/end
  A-->>H: agent/status idle
```

`followup` 不返回「这轮做完了」；等停稳用 `whenIdle()`。细节：[04](./04-一轮对话.md)、[05](./05-模型请求.md)。

<a id="tools"></a>

## 4. 一步里的工具怎么排

```mermaid
flowchart TB
  CALLS["assistant 工具调用（模型顺序）"]
  CALLS --> CLASS["按 executionMode 分类"]
  CLASS --> EX["exclusive → 屏障：独占跑完"]
  CLASS --> PAR["parallel-safe → 有界滚动池"]
  EX --> ORDER["策略 / 结果 / 结果上下文仍按模型顺序"]
  PAR --> ORDER
  ABORT["abort"] --> STOP["停新分发，排空已启动"]
  STOP --> SYN["未启动的：ABORTED_BEFORE_DISPATCH 合成结果"]
```

`maxParallelToolCalls`（默认 10）限制并行池；`1` 等于串行。细节：[06](./06-工具调度.md)。

<a id="cancel"></a>

## 5. 取消要点

```mermaid
flowchart LR
  C["cancel(cause)"] --> CLR["默认清空 inbox"]
  C --> AB["abort 当前活动 signal"]
  AB --> LATCH["收敛前的唤醒可锁存 wakeRequested"]
  LATCH --> REPLAY["idle 时重放，无需再 send"]
  DISP["disposed 取消"] --> NOLATCH["从不锁存"]
```

空闲时 `cancel` 是空操作。细节：[07](./07-取消与维护.md)。
