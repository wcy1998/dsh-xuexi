# 01 — 这是什么

对应总览：[对象关系](./00-总览.md#objects) · [优先级](./00-总览.md#precedence) · [进程 vs 会话](./00-总览.md#process-vs-session)

## 一句话

`@deepseek-ai/dsh-agent-default-model` 提供 **`ctx.agentDefaultModel`**：进程里**一份**共享的默认 `{ provider, model, reasoningEffort? }`，给各 Agent **入口**在「还没有会话级选型」时读。

它**不是**：

- 单个 Agent 的运行时模型切换器（那是入口 + [`installModelSelection`](../../agent/src/model-selection.ts)）；
- LLM 适配器或模型目录（不校验模型是否存在）；
- 会话持久化里那份已记录的选型（日志一旦记下，以日志为准）。

<a id="process-vs-session"></a>

## 「进程共享」≠「所有会话共用」

导读里的**进程共享**指：整个 `dsh` 进程里 **`ctx.agentDefaultModel` 只有一份服务**，headless、Web、ApiProxy 都读它当「默认模型从哪来」。

**不是**指所有会话永远用同一个模型，或共用同一段对话、inbox、日志。

| 层级 | 是什么 | 共享范围 |
|------|--------|----------|
| 全局 `ctx` | Cordis 插件树与服务（`ctx.agents`、`ctx.sessions` 等） | **整个进程一份** |
| `ctx.agentDefaultModel` | 默认 `{ provider, model, reasoningEffort? }` | **进程一份**；改 Settings 默认只影响之后 fallback 到默认的路径 |
| 单个 Agent / Session | `agent`、`session` 日志、`inbox`、`agent.ctx` | **每个会话各自一份** |

```text
进程（一份 ctx）
  ├── ctx.agentDefaultModel     ← 默认模型（共享）
  ├── ctx.agents                ← 登记册（共享容器）
  │     ├── Agent A + session A  ← 会话 A 自己的日志、inbox、模型选型
  │     ├── Agent B + session B  ← 会话 B 自己的…
  │     └── …
```

已有会话实际用哪个模型，见 [05 — 与单个 Agent 衔接](./05-与单个Agent衔接.md) 里的三级优先级：本进程内刚选的 → **会话日志** → 进程默认。改默认**不会** retroactively 改掉日志里已记下的模型。

和 [`dsh-agent`](../../agent/guide/00-总览.md#objects) 里 **`agent.ctx`** 的区别：`agent.ctx` 是**每个 Agent 私有**的子上下文（工具、提示词段只对它生效），不是进程共享。

## 为什么单独一个包

| 若没有它 | 有了它 |
|----------|--------|
| headless 自己写一套 `{ provider, model }` | headless 读 `ctx.agentDefaultModel` |
| Web ApiProxy 再写一套 | 同一服务 |
| 改部署默认要改多处 | base bundle 的 `cordis.patch.yml` 一处组合项 |

[`dsh-base`](../../../bundle/base/cordis.patch.yml) 默认挂载本插件并给出 `{ provider: deepseek-official, model: deepseek-v4-flash }`；用户可在 `settings.yaml` 的 `agent-default-model` 分节覆盖。

## 和 `dsh-agent` 的分工

| 包 | 管什么 |
|----|--------|
| [`dsh-agent`](../../agent/guide/01-这是什么.md) | Agent 把手、注册表、`agent/*`、**如何把选型绑到单个 Agent**（`installModelSelection`） |
| **本包** | **进程级默认选型从哪来、怎么存** |

创建 Agent 时的典型拼接：

```text
default = ctx.agentDefaultModel.currentSelection()
agents.create({
  agentOptions: { provider: default.provider, model: default.model },
  setup: (agentCtx) => installModelSelection(agentCtx, { current: default, … }),
})
```

`reasoningEffort` 若存在，由 `installModelSelection` 在 `agent/request`  waterfall 里写入请求，而不是写进 `agentOptions` 的静态字段 alone。

## 可选诊断

`@deepseek-ai/dsh-agent-default-model/invariant` 注册** intentionally empty** 的运行时 invariant：可变值关系已由 Settings schema 在校验层承担。根服务不会隐式加载它。
